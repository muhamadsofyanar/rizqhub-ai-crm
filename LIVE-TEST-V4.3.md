# Checklist Uji Operasional V4.3

Gunakan nomor dan grup milik sendiri terlebih dahulu.

## A. Device dan grup

- [ ] Account API Key dapat menyinkronkan daftar device.
- [ ] Device Key device uji berstatus valid.
- [ ] Device terhubung ke Brand yang benar.
- [ ] Device terhubung ke AI Agent yang benar.
- [ ] Tombol Ambil Grup menampilkan jumlah grup.
- [ ] Grup internal dikunci.

## B. Template

- [ ] Template teks tampil sesuai preview.
- [ ] Template media dapat dibuka melalui URL publik aplikasi.
- [ ] Variabel personal bekerja pada kontak uji.
- [ ] Duplikat template dapat diedit tanpa mengubah template asli.

## C. Audiens

- [ ] Bulk category dapat diterapkan ke beberapa grup.
- [ ] Preset statis hanya berisi grup yang dipilih.
- [ ] Preset dinamis mengikuti kategori.
- [ ] Salinan preset dibuat nonaktif.

## D. Pengiriman

- [ ] Personal teks ke satu nomor.
- [ ] Personal media ke satu nomor.
- [ ] Grup teks ke satu grup.
- [ ] Grup media ke satu grup.
- [ ] Multi-grup ke preset dua grup.
- [ ] Delay berjalan bertahap.
- [ ] Detail broadcast memperbarui status otomatis.
- [ ] Broadcast dapat dibatalkan sebelum semua target diproses.

## E. Operasional

- [ ] Daftar Inbox dapat di-scroll.
- [ ] Isi chat dapat di-scroll.
- [ ] Detail pelanggan dapat di-scroll.
- [ ] Deal dapat dipindahkan tahap.
- [ ] Nilai, pemilik, target selesai, Won/Lost dapat diperbarui.
